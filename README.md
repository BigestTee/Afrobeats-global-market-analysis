# Global Music Market Analysis: Identifying International Growth Opportunities for Emerging Afrobeats Artists

## Project Overview
This data analytics capstone explores international markets that may offer growth opportunities for emerging Afrobeats artists. By analyzing music chart and streaming-related data, the project aims to identify countries where Afrobeats has growing visibility and where emerging artists may benefit from targeted promotion.

## Research Question
**Which international markets offer the greatest growth opportunities for emerging Afrobeats artists?**

## Objectives
- Analyze Afrobeats chart performance across international markets.
- Identify countries showing increased Afrobeats chart presence over time.
- Compare markets based on visibility, consistency, and growth.
- Develop data-informed recommendations for emerging artists.

## Tools
- Microsoft Excel — data cleaning and preparation
- Tableau — data visualization and dashboard development
- GitHub — project documentation and version control

## Project Status
 **In progress — research and data collection**

## Planned Deliverables
- Project proposal and documentation
- Raw dataset and data sources
- Cleaned Excel workbook
- Tableau visualizations and dashboard
- Final presentation
- Recommendations based on findings

## Data and Scope
The project will use publicly available music chart data. The final date range and market coverage will be confirmed after reviewing the available dataset.

## Limitations
Chart visibility and streaming performance can indicate audience interest, but they do not directly measure revenue, concert demand, or marketing conversion.
