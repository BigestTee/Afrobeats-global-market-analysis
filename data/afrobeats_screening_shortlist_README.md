# Afrobeats screening shortlist

`afrobeats_screening_shortlist.csv` is a manually reviewable screening shortlist drawn from `afrobeats_candidate_pool.csv`. It is not a verified Afrobeats dataset, a complete catalogue, or a set of genre findings.

The shortlist prioritizes candidate records whose credited artists match the discovery list in the first or second credit position. Artist credit order and title markers such as `feat.` or `with` are discovery signals only. They do not establish billing roles or verify a track's genre. Coverage bands are sampled within priority groups so lower-coverage candidates can remain available for screening.

Each Spotify track ID remains a separate record. Review fields are left blank except `classification`, initialized as `Uncertain/Unclassified`. Apply the project classification codebook and record track-specific evidence before changing a classification.
